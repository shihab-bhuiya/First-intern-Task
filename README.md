# Intern Portfolio

A modern personal portfolio website for Mazidul Hakim built with Next.js 16, React 19, TypeScript, and Tailwind CSS. The project presents a professional digital profile with a dark, premium tech aesthetic and sections covering leadership, experience, skill sets, case studies, certifications, and contact information.

# Live Link : https://first-intern-task-mhbw.vercel.app/

## Project overview

This site is a single-page portfolio that reads like a polished executive profile. It is structured as a long-form landing page with a sticky navigation bar and multiple sections, each highlighting a different part of the professional story.

The page flow is:

1. Navbar
2. Hero section
3. Marquee / rotating expertise strip
4. About
5. Expertise
6. Case Files / impact stories
7. Experience timeline
8. Certifications
9. Professional qualifications
10. Contact

The overall design uses a navy/black background, cyan and lime accents, and a clean type-led presentation inspired by modern SaaS and personal branding websites.

## File-by-file explanation

### Root configuration

- `package.json` contains the project scripts and dependencies.
- `tsconfig.json` defines TypeScript settings.
- `next.config.ts` contains framework configuration.
- `eslint.config.mjs` controls linting rules.
- `postcss.config.mjs` is used for Tailwind/PostCSS processing.

### App shell and entry

#### `src/app/layout.tsx`
This is the root layout that wraps the application. It sets:

- HTML language
- font variables from Geist
- metadata such as title, description, author, and robots
- global body styling
- the main content wrapper

This file is the foundation for the app and is where the site metadata is defined.

#### `src/app/page.tsx`
This file assembles the portfolio page in the correct visual order. It imports and renders the core sections in sequence:

- Navbar
- Hero
- Marquee
- About
- Expertise
- Case files
- Experience
- Certificates
- Qualifications
- Contact

This is the page composition file for the full portfolio experience.

#### `src/app/globals.css`
This file includes:

- Tailwind import
- CSS variables for background and foreground colors
- dark theme defaults
- base body styling

## Main components

### `src/components/Navbar.tsx`
The fixed top navigation bar.

Features:

- desktop nav links for sections
- active section highlighting
- mobile menu toggle
- CTA button to contact section

This component uses the Intersection Observer API to highlight the section currently in view.

### `src/components/Hero.tsx`
The first visible hero section.

Contains:

- professional title and status line
- headline and intro text
- call-to-action buttons
- network connection graphic with location nodes

This is the main introduction section and sets the tone for the portfolio.

### `src/components/Marque.tsx`
A horizontal scrolling marquee component used to display repeated technology and capability labels.

It fetches items from:

- `public/data/marque.json`

This keeps the repeated list easy to update without touching the component itself.

### `src/components/About.tsx`
This section provides the profile summary and important statistics.

It includes:

- biography text
- quantitative metrics like years of experience, budgets, uptime, and branches supported
- a quote callout

### `src/components/Expertise.tsx`
A capability overview that groups skills into categories such as:

- Cloud & identity
- Network & security
- Cybersecurity
- Data, AI & automation
- Virtualization & DR
- Leadership

Each group has a title, short description, and list of skill tags.

### `src/components/CaseFile.tsx`
This section presents story-based case studies and transformation projects. Each card includes:

- category label
- case number
- project title
- summary
- result list with supporting technologies

The content is designed around infrastructure, security, modernization, and resilience work.

### `src/components/Experience.tsx`
A timeline view of career progression.

This component includes:

- year range
- role title
- contract dates and location
- expandable detail list for each role

It is interactive and allows the user to expand each entry.

### `src/components/Certifications.tsx`
Displays professional certifications as a card grid.

Each item includes:

- icon image
- certificate name
- styled card layout

### `src/components/Qualifications.tsx`
Displays academic and formal qualifications in a neat card grid.

Each card includes:

- image asset
- qualification title
- accent top border

### `src/components/Contact.tsx`
This is the final contact section.

It contains:

- email input field
- message textarea
- submit action UI
- a simple front-end "sent" status update

The form is a UI component and currently simulates success without backend submission.

### `src/components/SectionLabel.tsx`
A reusable component used to render a small section label with a number and label name like "02 / About".

## Public assets and data

### `public/data/marque.json`
This file contains the text list used by the marquee component. It is easy to edit if you want to change the rotating items shown in the moving ticker.

### `public/certificate/` and SVG assets
These assets power the certificate and qualification visuals. They are stored as local files and loaded directly into the UI via Next.js Image.

## How the site is organized

The project is intentionally built as a single-page portfolio:

- global background and typography are controlled from the app shell
- each section is a standalone, reusable React component
- the homepage simply composes them together
- data-heavy content is kept in arrays inside each component or in JSON under `public/data`

This makes the project easy to maintain because individual sections can be edited without disturbing the rest of the page.

## Local development notes

- The app is built for modern browsers.
- Styling is handled primarily with Tailwind utility classes.
- The site is designed as a dark, high-contrast portfolio with strong visual hierarchy.
- The portfolio content is mostly static but structured in a way that is easy to replace with real client data, portfolio items, or new roles.

## Typical customization points

If you want to update the project later, these are the most common places to edit:

- content text in `src/components/*.tsx`
- hero intro and copy in `src/components/Hero.tsx`
- stats and profile copy in `src/components/About.tsx`
- skills in `src/components/Expertise.tsx`
- experience history in `src/components/Experience.tsx`
- certs/qualifications in `src/components/Certifications.tsx` and `src/components/Qualifications.tsx`
- marquee content in `public/data/marque.json`
- page metadata in `src/app/layout.tsx`

## Summary

This project is a polished one-page portfolio website for an IT and cybersecurity professional. It is organized into modular, reusable sections and built on a modern Next.js stack with good maintainability and easy editing. The design emphasizes credibility, technical leadership, and business impact—matching the profile it represents.

If you are reopening this project later, the quickest way to understand it is to begin with:

1. `src/app/page.tsx` for the page layout
2. `src/components/Navbar.tsx` for navigation structure
3. each section component for specific content
4. `public/data/marque.json` for marquee content
5. `src/app/layout.tsx` for metadata and app shell

This is the structure of the project from top to bottom, and it should be easy to follow even when revisiting the code after time away.
